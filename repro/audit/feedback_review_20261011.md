## 3. 근거 상세

### 3.1 수치 재계산 (`check_claims.py`)
- merged.jsonl 3,000행 = 1,000 pid × 3 방법. `llm_used` 참 30행, `correct_rule` 존재 30행, 그중 정오 변경 1(341 TSR). `correct_recorded≠correct` 5행(v3 재채점 4 + LLM 1; EF L1312 "재채점으로 정오 바뀐 행 4"와 정합).
- Holm: `final_judgment.py` L57-60은 step-down 구현이 맞다(p 정렬 후 min(1, max(2·p₁, p₂))). 재계산 0.0667 / 1.0 일치.
- 민감도 CI 분류 전부 확인: 규칙만 2.2[0.3,4.1] / 0.0[−1.9,1.8] / 2.2[0.4,3.9]; (b) 2.6[0.4,4.9] / 0.5[−1.8,2.8] / 2.1[0.1,4.1]; (c) 3.0[0.5,5.5] / −0.9[−3.3,1.5] / 3.9[2.0,5.7]. 모두 VisRef−ST "크기 다름", VisRef−TSR "재현 안 됨", TSR−ST "재현됨"(CI가 2.4 포함). af 행 수 ST 239 / TSR 187 / VisRef 225 → (c)에서 ST가 가장 불리해 TSR−ST가 3.9로 커짐(사후 관찰 유지가 맞음).
- 논문 값 직접 확인: `VisRef_plain.txt` L1488 "46.1% (ST) and 48.5% (TSR) to 52.0%", L1545 "InternVL-1B 46.1 48.5", L1534 "52.0"; |Vk| = m은 L536.
