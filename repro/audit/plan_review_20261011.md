## 검토 판정 요지
- 계획(Set N 형식 변형 329문항 + Set C 정지 여유 A 344문항)은 정확도 판별력이 거의 없고 메커니즘 지표만 얻는다. Set N은 ST/TSR/VisRef 예측이 거의 동일(주 세션 계산 327/329)하고 fill close층도 4:6.
- 핵심 신규 관찰(사후 탐색): 저장된 1단계 정지 probe 답(`</think>\n\n\boxed` 직후 즉답, T=1, probe 난수열 pid별 공통)을 채점하면 VisRef가 TSR보다 높다. 차이는 전부 불확실(H≥δ) 문항에서 나오고, 같은 문항의 최종 답(이어가기 후)에서는 사라진다 → "V_1 정보는 즉답에서 쓰이지만, 이어가기 구간(94–97% 상한 절단 + 강제 답)이 이득을 지운다"는 가설.
- 권고 순서: 0) 이 관찰을 사후 탐색으로 기록 → 1) 저자 메일 지금 발송 → 2) 사전등록 즉답 확인 실험(1,000문항, TSR_imm / VisRef_imm / Random_imm / Rel_imm, 시드 3개, Mac 3–5h 또는 T4 ≤1h) → 3) 조건부: 불확실 문항 접두 100–150에서 이어가기 단계 상한 4,096(총 10,240 유지) TSR·VisRef 재실행. 보류: "H before V", 2B, 상한 전면 인상, Set C 여유 A, Set N 형식 변형 전수(n=100 메커니즘만).
- 필수 수정: 정확도를 1차 결과로 두지 말 것; z_1 토큰 id·DPP 선택 인덱스가 저장되지 않아 재인코딩이 바이트 동일이 아님(hidden_rank_check 12문항 중 5 불일치) → 같은 실행 안 기준선 포함, 이후 실행부터 id·sel 저장; 자유 생성 변형에는 TSR 대조군 필요; Set C는 사후 변수 선택(두 방법 모두 H<δ)이라 일반화 제한.
