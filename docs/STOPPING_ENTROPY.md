# 멈춤 엔트로피를 재는 방식: 시험 기록 모음

이 문서는 "멈춤 엔트로피 H를 어떻게 잴 것인가"를 다룬 시험만 시간순으로 모은 것이다. 각 숫자의 원문은 실험 기록
(`docs/EXPERIMENT_FLOW.md`, 날짜 항목 이름으로 표시)과 초기 기록(커밋 4776f6a의 같은 파일, 줄 번호로 표시)에 있다.
영어 요약은 [REPORT B1](../REPORT.md#26-setting-checks-how-the-unstated-settings-were-chosen)에 있다.

## 1. 무엇을 정해야 했나

- 논문은 생각 단계 k가 끝날 때마다 답 분포의 엔트로피 H_k = −E_y[log π_θ(y | x, τ_1:k)]를 재고, H_k < 0.25이면
  생각을 멈춘 뒤 최종 답을 새로 뽑는다(Algorithm 1 12–17행, 4.1.2절; `VisRef_layout.txt` L325–330, L377, L415).
- 논문은 이 기댓값을 어떻게 계산하는지(답을 몇 개 뽑는지, 어디까지를 답으로 보는지, 평균인지 합인지, 온도)를 적지 않았다.
  이 기준으로 인용된 Ghosal 등은 답을 여러 개 뽑아 최종 답 값 분포의 엔트로피를 쓴다(구현 근거 문서 X-11).
- 그래서 측정 방식을 직접 정해야 했다. 아래에서 "측정용 답"(REPORT의 *sampled answer*)은 H를 재려고만 뽑고 버리는 답이다.
  `smoke`, `smoke2`, `smoke3`은 본 실험 전에 수십 문항으로 돌린 작은 시험 실행의 폴더 이름이다(`repro/kaggle/runs/`).

## 3. 같은 응답이나 문항에서 두 방식을 비교한 것

- 같은 응답에서 계산 방식만 바꿈:
  - 확률 기준·종료 토큰 포함 여부(초기 기록 L303)
  - 평균과 합(`smoke2`)
  - 형식 토큰 분해(`smoke3`)
  - 닫는 괄호 묶기(`main_s0`)
- 같은 단계에서 문맥만 바꿈: 이미지 있음과 없음(VisRef-fill, A6).
- 없음: "풀이를 쓴 뒤의 답"과 "`</think>` 바로 뒤의 답"을 같은 문항에서 나란히 잰 결과, 그리고 답 여러 개로 잰 값과 답 1개로 잰 값을
  1B 모델의 같은 문항에서 비교한 결과.

## 4. 제안했으나 실행하지 않은 것

- 다중 표본 H(Ghosal 방식)를 VisRef-fill 실행에 함께 기록하는 안:
  - 제안: "검토: 정지 통계 H의 추정 방식 — 논문에 더 가까운 후보"
  - 철회: "정정: Ghosal식 다중 표본 H 그림자 기록 제안 철회"
  - 철회 이유: 예전에 써 보고 내려놓은 방식이고, T4 메모리와 실행 시간에 비해 예상 효과가 작다는 판단.
- 확인 실험 전 사전 점검: "다음 실험 후보: 가장 충실한 설정으로 확인 실험" 항목, 작성자 결정, 아직 실행 전.
  - 저장된 첫 단계의 일부 문항에서 같은 문맥으로 네 가지를 함께 계산한다.
    - (1) 온도 1·답 1개
    - (2) 온도 0.6·답 1개
    - (3) 답 8개의 답 값 분포 엔트로피(온도 1)
    - (4) (3)과 같은 것을 온도 0.6으로
  - 방식마다 0.25 아래로 멈추는 비율, 멈춤 판정의 일치율, 판정 한 번에 드는 시간을 본다.
  - 문항 수와 "크게 갈림"의 기준은 실행 전에 적는다.
- 단계 상한 4,096으로 다시 실행: "검토: 단계 상한 4,096 재실행의 가치". 기존 자료로 판단했고 실행하지 않음.

## 5. 지금까지 알게 된 것

- 같은 응답이라도 답 구간·평균/합·확률 기준을 바꾸면 0.25 판정이 뒤집힌다. 측정 방식이 멈춤 행동을 크게 좌우한다.
- 풀이를 쓴 뒤의 답 부분에서 재면 이미 답을 정한 뒤라 엔트로피가 거의 0이었다(`smoke`). 응답 전체에서 합하면 길이 때문에 거의 멈추지 않았다(`smoke2`).
- 지금 방식(`\boxed` 뒤 상자 안 답 1개의 합)에서는 모델이 스스로 생각을 닫은 뒤 이어 간 경우가 드물고, 이어 가기는 대부분 1,024토큰 상한에서 잘린 뒤에 일어났다.
- 답 1개의 토큰 엔트로피 합은 평균적으로 답 분포 엔트로피와 같지만(연쇄 법칙) 값의 흔들림이 크다. 답 여러 개로 잰 값과의 차이는 이 모델에서 재 보지 않았다.

## 6. 한계

- 설정 시험은 문항이 10~60개였고, 그 문항은 최종 1,000문항에도 들어 있다.
- 예전 코드 시기의 시험은 코드·상한·모델(1B와 8B)이 서로 달라 숫자를 직접 비교할 수 없다.
- 2.3절의 관찰은 결과를 본 뒤의 서술이며 판정에 쓰지 않았다.
