# smoke 전 독립 검토 (2026-10-07)

검토자: 코드 작성에 참여하지 않은 별도 에이전트(Sonnet). 논문 본문, Fig.1/2/3/4/5, Algorithm 1, 부록 표를 `repro/` 코드와 대조했다(읽기 전용).

## 결론
- 충족: Eq.1 ST, Sec.3 TSR(적응형 정지 포함), Eq.3 τ 순서(z_k → V_k → c), Markov 가정, Eq.6–11 kernel과 Chen greedy, m=⌊0.3|V|⌋, Algorithm 1 각 줄(V_k 포함 τ_1:k에서 H_k 계산, strict `<`, Kmax, 최종 답 재샘플), δ/m/Kmax 값.
- 명백한 코드 버그는 없음. 엔트로피 위치 정렬, chunk 재제출, 컨텍스트 순서, DPP 갱신식을 확인함.

## 반영한 사항
1. 이어가기 문구를 `Wait` → `Wait, think more`로 변경(Fig.1/Fig.2 문구).
2. DPP rank 부족: Z가 input embedding이라 rank(L) ≤ 고유 토큰 수다. 실측 규모 시험(|V|=3328, 600토큰 중 고유 250개)에서 m=998 중 DPP로 고른 것은 225개였고 나머지는 relevance 채움이었다. L+εI 변형인 `visref_reg`(998개 전부 log-det greedy)를 추가해 smoke에서 비교한다(사용자 결정).
3. 엔트로피는 평균(사용자 지정 H)과 함께 합(`H_sum`)과 span 길이를 기록한다. 논문의 시퀀스 엔트로피는 합에 더 가까울 수 있다는 지적을 사후 비교용으로 남긴다.
4. `summarize.py`에 `dpp_frac_mean`(n_dpp/m)과 `mean_n_visual`을 추가했다.

## 남은 위험 (smoke에서 확인)
- 토큰 상한(8192/16384)과 fp16, T4 환경 차이: `step_end=cap`, `stop_reason=budget`, `forced_close` 비율.
- 시각 토큰 노름 편향 가능성: 필요 시 random/relevance-only 소규모 점검.
- 1,000문항 단일 seed의 표준오차는 약 1.6pp로, 방법 간 차이(2.4~3.5pp)와 비슷한 크기다.
- 논문 내부 불일치: Table 3 diversity-only 77.4 vs Table 8 λ=0 71.2, 본문 m=20% 76.1 vs Fig.4(b) ≈77.3, Table 1 캡션 "all methods".

# Fable 5.1 논문 충실도 검토 (smoke2 전)

판정: 단계 정의(자연 `</think>`, 1단계 = ST 전체 trace), 재주입 위치(z_k 뒤), probe 폐기, Wait 이어가기, DPP greedy, R1 prompt, 타일링(평균 1792 ≈ 논문 1772), m/δ/Kmax는 논문과 맞는다.

지적과 처리:
1. `<img>…</img></think>` 재주입이 1B 모델을 "새 이미지 + 새 질문"으로 오인시킨다. probe에 두 번째 `</think>`가 visref 7/9, visref_reg 8/9였고(TSR 1/10), 질문 환각("Question:", pid 243 페르시아어)이 있었다. → 태그 없이 주입하는 `visref_raw`를 추가해 A/B로 비교한다.
2. H 작동 영역 확인을 smoke2의 1차 목적으로 둔다. 1단계 H<0.25 비율이 10% 미만이거나 90% 초과면 정지 규칙이 사실상 꺼진 것이다. 응답 토큰 평균 entropy는 δ=0.25와 양립하는 가장 방어 가능한 단일표본 추정이다.
3. DPP의 Z: 입력 임베딩이라 rank가 부족하다(smoke1 n_dpp/m≈0.47). contextual hidden state를 쓰면 rank≈T_k가 되어 논문의 8B 수치(615 ≥ 531)와 맞는다. visref_reg는 수치 땜질이다. → smoke2 결과를 본 뒤 `visref_hs`를 다음 smoke에서 검토한다.
4. 정지 시 probe 답 재사용 제안 → 채택하지 않음. 정지 결정에 쓰인 표본이라 선택 편향이 생기므로 Algorithm 1의 별도 재표본을 유지한다(사용자 결정).
5. 논문 내부 불일치: Fig.3/6에서는 VisRef의 thinking 토큰이 ST의 수 배로 보이지만 Table 5 지연은 +1.1s에 불과하다. smoke2의 k 분포가 경험적 답이 된다.
